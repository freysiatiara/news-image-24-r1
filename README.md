**The World in One Day — Tuesday 24 November 2026.** A newspaper front page
that sums up the day's world news in one image: Ukraine's sea drones sink the
Russian corvette Merkury off Libya, the AI market rout rolls into Asia, 24 dead
in the Banten factory fire, COP31 ends with no deal, and India–Nepal sign eight
deals with a ₹15,000 crore package — 31 stories across 7 regions, each tagged
REPORTED / CLAIM / ONGOING, with a DATE CHECK box that says honestly which day
each lead is from.

## Run it

```sh
python3 draw.py        # renders entry.png (1024x1024, deterministic)
python3 main.py        # writes /output/entry.png
```

`main.py` uses only the Python standard library and no network; two runs write
byte-identical output.
